# 视觉素材放置说明

这个目录用于放开发期的视觉素材，**不会进入公开构建**，也不会被打包进前端产物。

## 需要什么

1. `persona.png`（或 .jpg）：个人卡通形象静态原图
   - 清晰、正面；透明背景或纯色背景都行
   - 尽量给原图，不要截图压缩版
2. `ref-*.png`：视觉参考图 1–3 张
   - 例如 `ref-home.png`（首页构图）、`ref-card.png`（卡片质感）、`ref-color.png`（配色）
3. 可选：`persona.mp4`（循环视频，静音）

## 请在消息里补充

- 每张参考图参考的是：首页构图 / 卡片样式 / 配色 / 字体 / 动效节奏
- 昵称、空间名（可选）

## 说明

- 首页个人形象最终由你在「设置 → 首页形象」里本机上传，存 IndexedDB，不上传服务器。
- 这里放文件只是为了开发期预览与截图比对。
