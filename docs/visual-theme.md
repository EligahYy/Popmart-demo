- 个人形象与视频：运行时上传，存本机 IndexedDB，**不放进 `public/`、不进公开构建**

## 替换流程

1. 从参考图取 3–5 个主色：背景、卡片、文字、强调、警示。
2. 确认圆角与阴影基调（扁平 / 轻投影 / 重质感）。
3. 定字号层级（标题、正文、说明）与字重。
4. 定动效节奏；若参考图偏静，`--motion-float-duration` 调长或关闭。
5. 用真实素材验证首页构图：个人形象在背景，IP 入口在前景可点，**不遮挡新增与导航**。
6. 对比度检查：正文与背景对比度 ≥ 4.5:1；状态不能只靠颜色，需同时有文字。
7. 截图对照参考图，记录差异。

## 硬性约束（来自 PRD）

- 不预设奶油白、浅粉、淡紫等固定色系；以用户参考图为准。
- 不照搬泡泡玛特商城的按钮、价格区、促销样式。
- 首页不出现消费金额、额度或预算提示；这些只在账本。
- 缺少官方动画时用「官方静态形象 + 轻动效」，不得称为官方角色动作动画。
- 尊重 `prefers-reduced-motion`，动效必须有静态兜底。

## 个人形象抠图

- 用 macOS Vision 的 `VNGenerateForegroundInstanceMaskRequest` 做主体分割，
  输出透明 PNG：`assets/persona-cutout.png`
- 抠图只移除背景，不改变人物形象
- App 内仍通过「设置 → 首页形象」本地上传该 PNG，不打包进公开构建

## 首页场景与动效

- 个人形象**只存本机**（IndexedDB），不打包、不上传；未设置时首页显示虚线占位
- 支持两种本机素材：
  - 常态：图片或静音循环视频
  - 打招呼：2–5 秒短视频，点击人物时播放一次，播完回到常态
- 场景：左侧为用户提供的粉色 3D 收纳架渲染图（抠掉绿底），柜内两层摆放 6 个 IP：
  Twinkle Twinkle、CRYBABY、NYOTA、Zsiga、DIMOO、Hirono（小野）
  - 素材来源：用户放在 `assets/shelf/` 的 3D 渲染图
  - 6 个 IP 用 Vision 逐张抠图，缩放到统一高度后站在隔板上，补投影
  - `src/assets/shelf3d.png` + `src/assets/ips/*.png` 为构建资源
  - 仅为个人使用的二创展示；若公开部署需自行确认版权
- 柜体与人物为 2.5D 合成：柜子是 3D 渲染图，人物是抠图 + 投影；不是可旋转的 3D 模型
- 打招呼视频背景基于当前场景截图烘焙，换素材/布局后需重新烘焙
- 视频人物亮度与静态形象匹配：原视频平均亮度约 161，静态形象约 130；
  合成时做 -0.35EV 曝光 + 高光压缩曲线，输出平均亮度约 124，避免点击后「过曝」
- 打开首页：人物从下方淡入
- 点击人物：有打招呼视频就播放一次；没有则整体轻微摇摆 + 气泡「嗨，欢迎回来～」+ 星星粒子；收纳架轻微晃动
- 视频加载失败或超过 6 秒会自动回到常态，不会卡在播放态
- 打招呼视频若带灰底，先用离线工具逐帧抠图，并用**当前首页截图同位置**作为背景烘焙
  （`assets/greeting.mp4`，5.03s / 834×1112 / 3.6MB）
- 打招呼视频为 **左半彩色 + 右半蒙版** 的单文件 MP4；运行时用 WebGL 把蒙版亮度作为 alpha，
  只显示人物，不覆盖收纳架或场景，也不需要放大
- 视频人物按静态形象放大 12.6% 并居中，尺寸与位置对齐
- 兼容 Safari / Chrome（H.264 + WebGL），已用 canvas 像素断言角透明、人物不透明
- 不再使用烘焙背景，换场景/主题也不需要重新处理视频
- 换主题、改布局或换形象位置后需要重新烘焙视频背景，否则接缝会露出来
- 空间名称：默认「红彤彤收纳」，可在设置修改，存 preferences 并随备份迁移

## 首页构图

- 顶部：品牌字 + 设置入口
- 顶部：品牌字 + 设置
- 主视觉：**抠图后的个人形象居中站在卡片底部**，问候语与三色统计药丸在左上方
- 背景：粉 → 杏 → 鼠尾草绿渐变，配淡紫/绿色圆形色块
- 下方：两列 IP 卡片网格（封面、持有数量角标、系列/款数），卡片按序轮换粉/绿/紫/杏底色
- 导入入口只保留在底部中间 ＋，首页不再放导入按钮

## 素材接入

- 个人形象：设置 → 首页形象 → 选择图片或视频（本机保存，可移除）。
- IP 封面：来自已拥有款式图片，每次启动轮换（同会话稳定）。
- 官方素材：导入系列时缓存到本机；未缓存时回退远程地址。
