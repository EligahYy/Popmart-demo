# iPhone 实机验收清单

目标设备：iPhone 15 Pro Max（iOS 当前版本）
前置：HTTPS 地址（PWA 安装、Service Worker、离线冷启动都要求安全上下文）。
局域网 HTTP 地址只能检查布局与手势，**不能**完成安装与离线项。

## 临时 HTTPS 隧道（本机验收）

1. 保持 Mac 开机且联网，运行：

   ```bash
   cd /Users/hongtongtong/popmart_app
   ./scripts/serve-tunnel.sh
   ```

2. 终端会打印 `https://xxxx.trycloudflare.com`，这就是手机访问地址。
   该地址只在隧道进程存活时有效；结束进程后地址会变。
3. iPhone Safari 打开地址 → 分享 → 添加到主屏幕。
4. 后续修改代码后：重新构建并重启本地服务，隧道不用动，地址不变。
5. 手机上从主屏幕图标重新打开；若仍是旧版本，强制关闭后重开，
   应用会提示「新版本已就绪」，点更新即可。不要清理 Safari 网站数据，
   否则本机收藏与备份会一起清空。

## 准备

1. 按 [deploy.md](deploy.md) 部署到 HTTPS 域名，或使用可信的 HTTPS 隧道。
2. 手机上打开地址，先导入一个系列并录入 2–3 只，作为验收数据。
3. 在「设置 → 首页形象」上传个人形象图片。
4. 本机诊断里确认：款式/订单/明细数量正确、Service Worker「已接管」。

## 清单

### 1. 主屏幕安装（AC24）
- Safari 打开 → 分享 → 添加到主屏幕 → 从图标启动
- 期望：全屏无浏览器地址栏；底部导航不压住安全区；能正常导入与记账

### 2. 安全区与键盘（AC22、12.2）
- 打开「欢迎新宝宝」→ 选款式 → 键盘弹出
- 期望：保存按钮不被键盘遮挡；面板可滚动到按钮；关闭键盘后布局不塌

### 3. 卡组滑动与页面滚动（AC10、AC11）
- 某个 IP 下准备 2 个系列，其中至少一个系列有 5 款
- 期望：同时最多 3 张卡；左右滑动只影响当前系列；上下滚动不被卡住

### 4. 身份卡（AC12、AC37）
- 点击卡片 → 翻面 → 关闭
- 期望：回到原 IP、原系列、原选中款式；正反面都没有金额

### 5. 首屏密度（AC21）
- 收藏夹首屏数系列数量
- 期望：约 4–6 个系列，两列布局不拥挤

### 6. 素材兜底与减弱动效（AC22、AC34）
- 设置 → 辅助功能 → 减弱动态效果
- 期望：IP 封面不再漂浮；图片加载失败时显示「暂无图片」占位而不是破图

### 7. 离线冷启动（AC20、AC43）
- 联网打开一次并等待图片缓存完成（设置 → 缓存全部图片）
- 开启飞行模式 → 从主屏幕图标冷启动
- 期望：小窝、收藏、账本可打开；已缓存图片可见；导入提示需要联网

### 8. 备份导出与恢复（AC43、12.3）
- 设置 → 导出备份 → 保存到「文件」
- 修改一条数据 → 恢复备份 → 确认替换
- 期望：展示备份时间与记录数；恢复后数据回到备份时点；旧数据集保留为 retired

### 9. 更新提示（10.3）
- 部署新版本后从主屏幕打开
- 期望：提示「新版本已就绪」，正在填写的表单不被强制刷新

## 已知限制

- 局域网 HTTP 地址无法安装 PWA、无法注册 Service Worker。
- iOS 对存储有配额与清理策略，长期可靠性仍依赖导出备份。
- 个人形象与收藏数据只在本机；换设备请用备份文件迁移。
